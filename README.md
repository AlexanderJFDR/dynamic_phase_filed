# Dynamic Crack Branching Phase-Field Benchmark

This project reproduces a dynamic crack branching benchmark using the phase-field regularized cohesive zone model (PF-CZM).

## Description

This repository contains an ABAQUS user element subroutine (UEL) implementing the phase-field model for dynamic fracture analysis. The model is capable of simulating complex fracture behaviors such as crack propagation and branching under dynamic loading conditions.

The code implements the phase-field regularized cohesive zone model with a BFGS quasi-Newton solver, supporting dynamic fracture analysis and various softening constitutive relations.
